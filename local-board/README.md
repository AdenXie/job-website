# 秋招信库 · 本地投递看板

一个运行在你自己电脑上的投递看板：把在[秋招信库](https://jobs.adenxie.com.cn/)收藏的岗位同步过来，按“想投 → 已投递 → 测评/笔试 → 面试中 → Offer / 已结束”整理投递进度，记录笔试面试时间和备注，还能导出日历提醒。

**所有数据只保存在你的电脑里**（`data/board.json`），不会上传到任何服务器。看板需要在电脑（Windows、macOS 或 Linux）上运行，手机上无法使用。

## 第一次使用

1. **安装 Node.js（只需一次）**：需要 18 或更高版本。没有安装时，启动脚本会自动打开 [Node.js 下载页](https://nodejs.org/zh-cn/download)，下载“LTS”版本，一路点“下一步”安装即可。
2. **下载并解压**：在秋招信库“我的收藏”页面下载 `local-board.zip`，解压到一个固定的位置（例如“文档”文件夹）。不要直接在压缩包里运行。
3. **双击启动**：
   - **Windows**：双击 `start.bat`。
   - **macOS**：双击 `start.command`。
   - **Linux**：在终端里运行 `sh start.sh`。

   启动后会弹出一个黑色的命令行窗口，并自动在浏览器打开看板（地址是 `http://127.0.0.1:47321/`）。**使用期间不要关闭这个窗口。**

### 第一次运行时的安全提示

- **Windows 弹出“Windows 已保护你的电脑”**：这是因为文件是从网上下载的。点“更多信息”→“仍要运行”即可。
- **Windows 防火墙询问是否允许 Node.js 访问网络**：看板只在本机使用，点“取消”或只勾选“专用网络”都不影响使用。
- **macOS 提示“无法打开，因为无法验证开发者”**：在“访达”里**按住 Control 键点按** `start.command`，选“打开”，再在弹窗里点“打开”。只需要这样做一次。

## 同步收藏的岗位

1. 先按上面的步骤启动本地看板。
2. 打开秋招信库，进入“我的收藏”，点“同步到本地看板”。
3. 浏览器会打开看板并弹出确认框，显示将新增和已存在的岗位数量，点“确认导入”。

说明：

- **同步是单向的**：网站 → 看板。在网站上取消收藏，不会删除看板里的卡片；想删除卡片请在看板的卡片详情里操作。
- 已经在看板里的岗位再次同步时，只更新岗位信息（截止日期、链接等），**不会改动**你设置的状态、时间线、备注和标签。
- 同步的数据放在看板地址的 `#` 后面，只在你的浏览器里传递，不经过任何服务器。
- 看板里的“刷新岗位信息”会从秋招信库读取最新的岗位数据，更新截止日期等信息；网站上已经没有的岗位会标记“原岗位已下架”，卡片不会被删除。

## 日常使用

- **换状态**：电脑上直接把卡片拖到另一列；也可以用卡片上的下拉框（只用键盘时也能操作）。每次换状态会自动记录日期，可以在“详情”里修改。
- **详情**：记录下一步事项和时间（例如“二面 · 10/28 14:00”）、备注、标签。截止日期在 3 天内、或下一步事项在 24 小时内的卡片会高亮。
- **新增岗位**：不在秋招信库里的岗位，点“新增岗位”手动添加。
- **统计**：投递漏斗（各阶段数量和转化率）、每周投递数量。
- **日程**：列出所有截止日期和下一步事项；点“导出日历 .ics”可以导入手机或电脑的日历。

## 停止服务

关闭启动时弹出的命令行窗口即可（或在窗口里按 `Ctrl + C`）。下次使用时重新双击启动脚本，数据都还在。

## 备份与迁移

- 所有数据都在 `data` 文件夹里：`data/board.json` 是看板数据，`data/backups/` 里是每天自动保存的备份（保留最近 7 天）。
- **手动备份**：在看板上点“导出 JSON”，或直接复制整个 `data` 文件夹。
- **换电脑**：在新电脑上下载并解压看板，把旧电脑的 `data` 文件夹复制到新的看板文件夹里（覆盖），再启动即可。也可以在新看板上点“导入 JSON”导入之前导出的文件。
- **恢复备份**：先停止服务，把 `data/backups/` 里某一天的文件复制为 `data/board.json`，再启动。

## 升级

看板上的“检查更新”会对比秋招信库上的最新版本，有新版本时只会提示，不会自动修改你的文件。升级方法：

1. 停止服务（关闭命令行窗口）。
2. 下载新版 `local-board.zip`，解压到一个新文件夹。
3. **把旧文件夹里的 `data` 文件夹复制到新文件夹里**，然后用新文件夹的启动脚本启动。确认数据都在之后，再删除旧文件夹。

## 常见问题

- **不小心又双击了一次启动脚本**：没关系。看板发现自己已经在运行时，会直接打开浏览器，新弹出的窗口几秒后自动关闭，原来的窗口保持打开即可。
- **提示“端口 47321 已被其他程序占用”**：说明是别的程序占用了这个端口。请关闭那个程序后重试；也可以修改 `config.json` 里的 `port`，但秋招信库网站上的“同步到本地看板”按钮固定使用 47321 端口，换端口后只能用“导入 JSON”导入。
- **直接关闭命令行窗口会丢数据吗**：不会。看板上的每次修改都会立即保存到 `data/board.json`，关闭窗口只是停止服务。
- **点“同步到本地看板”后新标签页打不开**：请确认看板的命令行窗口还开着。
- **`config.json` 里的 `llm`**：为下一期“针对岗位定制简历”预留，届时会使用你自己的 API Key。目前留空即可，本版本不会调用任何大模型。

## 技术说明

- 只用 Node.js 内置模块，不需要 `npm install`；页面是不需要构建的静态文件。
- 服务只监听本机地址 `127.0.0.1`，局域网里的其他设备访问不到。所有请求都会检查 Host 头，修改数据的请求还要求来自看板页面本身，防止其他网站读写你的看板。
