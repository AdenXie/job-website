# 秋招信库

面向中国校招的岗位信息库：[打开网站](https://jobs.adenxie.com.cn/)。支持关键词和条件筛选、原始链接、截止日期提示及浏览器本地收藏，兼顾电脑和手机浏览。

岗位数据来自 [offer先生校招 API](https://developer.offerxiansheng.com/docs/quickstart) 与 [xixicc2027](https://github.com/xixicc186/xixicc2027)。本站约每 12 小时读取一次 offer 先生最近 24 小时的更新，并完整读取 xixicc2027 数据文件，只展示其中的校招岗位；实习和活动不收录。地点统一为省份和城市。本站保留来源、原始链接和数据更新时间；招聘状态未经逐条人工核验，投递前请以企业公告为准。已知截止日期过期的记录会在同步时移除；没有截止日期的记录无法据此判断是否仍在招聘。

## 简历生成器

站内附带一个纯前端的[在线简历生成器](https://jobs.adenxie.com.cn/resume/)：左侧编辑内容，右侧实时预览 A4 排版，支持三套模板切换、内容超出时自动压缩到一页，以及通过浏览器打印导出 PDF。简历内容只保存在当前浏览器的本地存储中，不会上传；可导出 JSON 备份后再导入。入口在首页右上角，源码位于 `resume/index.html` 与 `src/resume/`，随主站一同构建和部署。

已有 PDF 简历时可以点“上传 PDF”：页面用 [pdf.js](https://github.com/mozilla/pdf.js)（Apache 2.0）在浏览器本地读取文字，按版面位置和标题关键词识别基本信息、教育背景、实习与项目经历、专业技能、获奖与证书等模块，认不出归属的内容放进“其他内容”，核对补充后即可重新导出。识别基于规则，可能有误；扫描件或图片型 PDF 没有文字层，无法识别，双栏排版的识别效果较差。个别没有内嵌字符映射表的中文 PDF 会从 jsDelivr 按需下载映射表，简历内容本身不会离开浏览器。

三套模板的版式思路参考了以下开源简历项目（均为 MIT 许可的 LaTeX 模板），在此致谢。本站用 HTML/CSS 重新实现，没有复制其源码或字体：

- [billryan/resume](https://github.com/billryan/resume)：“经典”模板的居中抬头、通栏标题线与“名称在左、时间在右”的条目排法。
- [hijiangtao/resume](https://github.com/hijiangtao/resume)：“紧凑”模板面向中文单页简历的信息密度取舍。
- [heylong7/OpenCurve-Resume](https://github.com/heylong7/OpenCurve-Resume)：“色带”模板的全局强调色、条目色带与可选头像，以及字号、行距、边距可调的思路。

## 数据洞察

[数据洞察页](https://jobs.adenxie.com.cn/insights/)用图表汇总岗位库的整体情况：岗位、公司与城市数量，城市排行与省份方块图，行业、岗位族、届别分布，记录最多的公司，以及未来 8 周的截止日期。图表均为手写 SVG／CSS，没有引入图表库，也不使用地图数据。每张图下方注明计数口径：一条岗位可能同时计入多个城市、行业或岗位族；截止日期只覆盖提供了日期的约一成岗位，页面会标出覆盖率。点击城市、省份、行业、岗位族、届别或公司，会跳回首页并带上对应筛选条件。

页面只读取约 5 KB 的 `public/insights.json`，不加载完整的岗位数据。该文件由 `npm run build:insights` 从 `public/jobs.json` 聚合生成，定时同步后和每次构建前都会自动重新生成。岗位族（`family` 字段）由 `src/job-families.mjs` 中的关键词词典根据岗位标题归类，行业写法的合并规则在 `src/industries.mjs`。

## 为你推荐

首页排序里的“为你推荐”会按求职画像给岗位排序，并在每条岗位上用标签说明命中原因（例如 ✓ 后端开发 ✓ 上海 ✓ 2027届）。画像包含求职方向（最多 3 个）、意向城市、届别和可选的行业偏好，可以从简历生成器里的简历识别、上传 PDF 识别，或直接手动设置；每一项都能手动修改，手动修改不会被之后的自动识别覆盖，除非点击“从简历重新识别”。简历生成器里也有“用这份简历看推荐岗位”的入口。

原理：岗位数据没有职位描述（JD），只有标题、行业、岗位族、城市、届别等字段，所以这是按方向、城市、届别和行业的规则排序，不是语义匹配，也不给出“匹配度”百分比。届别不符的岗位会被排除（不限届别或未写届别的保留）；岗位族按稀有度加权，覆盖面很广的岗位族（研发/工程、职能、销售/市场）和列出很多岗位族的汇总记录会降权；城市、行业命中加分；7 天内截止的轻微加分，没有截止日期不扣分。岗位族由标题关键词推断，可能归类不准；推荐排序可以和筛选条件叠加使用。

隐私：读取简历、生成画像和打分都在浏览器里完成，不调用任何大模型或服务端接口。画像只保存方向、城市、届别和行业，存在当前浏览器（`campus-opportunities:profile:v1`），不复制姓名、电话、邮箱等简历内容；上传的 PDF 只用于识别画像，不会保存或上传。简历生成器里的示例简历不会被当作你的简历。

## 网址筛选

首页的筛选条件会同步到网址，可以直接分享或从数据洞察页跳转，例如 `/?city=上海&family=算法`。支持的参数为 `province`、`city`、`industry`、`family`、`cohort`、`batch`、`deadline`（`7`、`30`、`unknown`）、关键词 `q` 和排序 `sort`（`deadline`、`recommend`；求职画像本身不会写进网址）；当前数据里不存在的值会被忽略。首页的行业筛选与洞察页使用同一套写法合并规则（`src/industries.mjs`）。

## 本地投递看板

“我的收藏”里可以下载本地投递看板（`/downloads/local-board.zip`）：解压后双击 `start.bat`（Windows）或 `start.command`（macOS）启动，看板运行在本机 `http://127.0.0.1:47321/`，需要 Node.js 18 或更高版本，不需要安装任何依赖。点“同步到本地看板”会把收藏岗位的快照放在看板地址的 `#` 后面打开，数据只在浏览器里传递，不经过任何服务器；同步是单向的，网站上取消收藏不会删除看板卡片。看板按“想投 → 已投递 → 测评/笔试 → 面试中 → Offer / 已结束”整理进度，支持拖拽换列、状态时间线、下一步事项提醒、投递漏斗与每周统计、日程导出 .ics，以及整个看板的 JSON 导出导入。数据保存在看板文件夹的 `data/board.json`，每天自动备份，保留 7 天。

源码在 `local-board/`，不参与主站页面构建；`npm run build` 结束后会自动打包成 `dist/downloads/local-board.zip`，并生成 `local-board-version.json` 供看板的“检查更新”使用。面向用户的使用说明见 [local-board/README.md](local-board/README.md)。
